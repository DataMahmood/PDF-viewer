## Kaghaz PDF Viewer v1.0.0

Initial standalone release of the browser-based PDF annotation reader.

### Included

- Local PDF rendering with PDF.js
- Rectangle highlighting
- Freehand drawing and pen annotations
- Persian, Arabic, and English notes
- Select, move, recolor, edit, and delete annotations
- Eraser, undo, and redo
- JSON backup and restore
- Annotated PDF export
- Font-rendering fallback for difficult embedded fonts

### Download

Download `index.html` from the release assets and open it in a current browser.
